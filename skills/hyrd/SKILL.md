# 行业热点（hyrd）

用于用户要求“六大行业周报、行业热点、行业动态、近一周券商研报摘要”时。默认覆盖：集成电路、生物医药、化工新材料、高端制造、新能源、人工智能。

## 核心边界

- 数据源为通联数据研报接口；研报正文必须调用 `batchGetReportContentDomestic`，禁止调用 `getReportDownloadUrl`，也不要下载研报 PDF。
- 若当前 Codex 会话未暴露通联研报连接器工具，使用项目适配器 `python scripts/datayes_research.py`；适配器会动态读取接口 Schema、只从 `DATAYES_TOKEN` 环境变量取凭据，并在内存中处理响应。
- 研报发布日期按运行日向前滚动 7 个自然日筛选；保留实际 `publishTime`，不得把更早报告伪装成最新报告。
- 研报只用于发现候选事件和理解背景。最终新闻出处应优先为政府部门、监管机构、企业官网、中央媒体或中国大陆合规财经媒体；不得引用对中国大陆存在政治口径风险的境外社交媒体或新闻媒体报告。无法找到合规公开出处的事件，标注“公开来源未核验”，不要用券商研报冒充新闻来源。
- 只选“行业要闻、行业热点跟踪、公司/政策动态”等客观事件，不选商品价格、指数涨跌、估值、券商主观评级或投资建议作为新闻。

## 默认关键词与券商优先级

| 行业 | 关键词 | 对应优先券商 |
|---|---|---|
| 集成电路 | 电子行业周报 | 国金证券、东海证券、爱建证券 |
| 生物医药 | 创新药周报 | 华创证券 |
| 生物医药 | 医药生物周报 | 国信证券 |
| 生物医药 | 医药生物行业跟踪周报 | 东吴证券 |
| 化工新材料 | 新材料周报 | 山西证券、华福证券 |
| 化工新材料 | 大炼化周报 | 信达证券 |
| 高端制造 | 商业航天周报 | 华源证券 |
| 高端制造 | 航天军工行业周报 | 华泰证券 |
| 新能源 | 电力设备与新能源行业周报 | 中银国际 |
| 新能源 | 电力设备及新能源行业周报 | 华创证券 |
| 人工智能 | 数字经济周报 | 银河证券 |

每个关键词必须单独检索并优先匹配同一行的券商，不能把相近关键词或不同券商合并成一个检索条件。可在用户指定时扩展关键词，但不得删掉用户明确要求的行业或日期边界。

## 执行流程

1. 检查 `DATAYES_TOKEN`；缺失时停止并请求用户提供，不猜测或写入永久配置。
2. 通过通联 `research_search`（或项目适配器的 `search` 子命令）按关键词、`type=EXTERNAL_REPORT`、`orgType=1`、发布日期窗口检索候选；优先匹配指定券商和 `reportType=INDUSTRY`。
3. 读取少量入选报告的 `id` 后，按每批不超过 10 个 ID 调用 `batchGetReportContentDomestic`（或适配器的 `content` 子命令）。严禁使用 `getReportDownloadUrl`。
4. 在正文中优先定位“行业要闻/热点跟踪/政策/新闻/公司动态”等段落，抽取客观、可核验事件。每个行业选 1—2 条，优先“一条行业动态+一条政策解读”，没有政策时再选两条行业动态。
5. 对每条事件回查公开出处。新闻检索可使用 agent-reach 的 Exa；仅保留符合来源限制的结果。正文必须 100—200 字，解读不超过 100 字；解读不得写成授信审查、投资评级或宣传口号。
6. 输出 Markdown：每条包含标题、正文、解读、出处、原文链接；开头写信息窗口和来源限制；结尾列出实际使用的券商周报及发布日期，并明确“使用 `batchGetReportContentDomestic`，未使用 `getReportDownloadUrl`”。

## 质量检查

- 六个行业齐全；每条新闻有日期、具体事实、合规出处和可点击链接。
- 正文与解读分别满足字数要求；不把券商观点、价格跟踪、行情涨跌当成新闻。
- 所有周报均在最近 7 天内；若某关键词无合规结果，说明缺口而不静默替换。
- 扫描最终 Markdown，删除被禁止的境外社交媒体/新闻媒体引用，以及任何 `getReportDownloadUrl` 调用或链接。

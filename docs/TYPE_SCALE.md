# 门户字号规范

本项目的模板字号要求是固定的项目约束，不随每周数据更新变化。

## 相对字号规则

- `button` 类控件：在各自原始字号基础上增加 `3px`。
- 正文 `<p>`：在各自原始字号基础上增加 `2px`。
- `.card-foot`：在原始字号基础上增加 `1px`。

当前模板通过 CSS 变量统一管理增量：

- `--type-button-delta: 3px`
- `--type-paragraph-delta: 2px`
- `--type-card-foot-delta: 1px`

页面结构、颜色、间距、布局、响应式断点和交互不因本规范改变。移动端首屏正文同样保持正文 `+2px` 的增量。`npm test` 会校验这些变量和选择器，防止周更时误删字号规则。
